
# Patrimoine

Plateforme web dédiée à la découverte et à la valorisation du patrimoine culturel et historique.

## Fonctionnalités

- Consultation des monuments historiques
- Navigation par catégories
- Recherche et découverte des monuments
- Galerie d'images
- Gestion des monuments depuis un espace administrateur
- Gestion des villes et des pays
- Gestion des messages de contact

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Node.js

## Installation

1. Cloner le dépôt :

   git clone https://github.com/TON-USERNAME/Patrimoine.git

2. Créer la base de données `patrimoine`.

3. Importer `sql/patrimoine.sql` dans MySQL.

4. Configurer la connexion dans `includes/config.php`.

5. Lancer le serveur :

   php -S localhost:8000

6. Accéder à http://localhost:8000
